# 转译台设计

使用见[转译台](../features/cloud-agent.md)，配置与恢复见[交付配置](../operations/cloud-agent-delivery.md)、[运行手册](../operations/cloud-agent.md)。
本文件合并任务编排、Harness、审查、设备、交接与产物治理的设计约束。

## 状态与版本

- 工作台负责调度、权限和人工记录；Harness 负责工程阶段、门禁、证据与原生预算。
- 阶段由校验结果派生，模型总结、工具结束或生命周期展示不能授予通过。
- 任务保存 App、来源、材料版本、分支与模型；运行保存租约、工作区、实例及收据，事件支持游标回放。
- 主仓与登记内嵌仓固定源码快照，Android 只读；鸿蒙写入限当前任务工作树。
- `baseSha` 是比较基线；登记后继提交时使用 `harmonyHeadSha ?? baseSha` 校验 HEAD，不覆盖原基线。
- 材料与审批代次绑定。输入变化保留历史并使相关结论失效，不把旧批准迁移到新材料。
- MR 收件独立去重，范围不清、多 App 命中或来源无法核验时不猜测建单。

## 执行与恢复

- 分析、编码、独立代码审查与设备复核分职责隔离。等待人工不占模型执行实例。
- 分析单轮 60 分钟，编码单轮 180 分钟；回答结束后按有效证据和原生待办有限续行。
- 同职责检查点绑定任务、工作区、模型与原生 run；恢复前核验进程退出、工具结算和停止收据。
- 保留未变文件的已读覆盖，变化内容重新读取；预算不能通过新会话或新操作 ID 清零。
- 同工作树变更、审查与构建互斥。未知副作用保留恢复分类，不自动重放。
- 单个外部依赖只影响关联操作；仍可执行的查证和独立场景继续。
- `record-change` 按条目补录，未提供字段保留；人工排除和授权记录不可由模型修改。

## 审核与审查

- Scope / UI 决定绑定材料、展示正文、图片摘要、任务轮次和操作者；Worker 登记原生决定。
- HTML 原型隔离渲染，禁脚本、外部网络、表单和跳转；只读已登记且哈希一致的资源。
- 独立代码审查核对变更、可达链、反证与交互边界；缺证据或 P0/P1/P2 阻止构建。
- 审查每 30 秒核对输入；失效报告保留问题，不能复用通过结论。
- 已读分页按哈希复用，变化依赖重读。每页最多 6000 字符，每批最多两页。
- 单次审查最多 15 分钟，每批最多 8 次、累计 60 分钟；连续无进展停止并明确缺口。
- 缺少 human 记录的补充证据不当作批准，损坏或越界审批材料仍拒绝。

## 构建与设备

- 命令、SDK、缓存和设备来自管理员配置。新包绑定当前源码、精确参数、日志与 SHA256。
- native 执行器接收声明式动作与断言，观察值来自原生设备，不接受模型自报通过。
- 场景绑定当前安装、canonical 合同与真实 fixture；成功、失败、未执行分别保存。
- 只读观察与日志查询可用于 fixture 准备，不能因 fixture 未就绪整体封锁取证。
- 普通弹窗依控件证据处理，已批准业务交互不按文字一概拒绝；未知结果核对原操作。
- 模拟器不调用 HDC 系统录屏服务，改用截图、日志及连续画面；媒体 URI 不等于有效 MP4。
- `frame_motion` 至少三个稳定采样、间隔不小于 0.5 秒，保留原帧和指标并独立复核；不证明声音或失败回退。
- 独立设备复核按场景读取动作、断言、截图和原件摘要；只复用输入未变的有效报告，不跨包复用通过。
- 视觉人审保留原自动报告与分数，差异接受绑定当前包和具体状态；人工排除项不得标为 passed。

## 设备结论与交付

- 代码审查与构建通过后，设备执行结束生成 `passed` 或 `incomplete`，绑定材料、源码、HAP 与报告摘要。
- 未完成结论保留缺项并进入提测，不改写 Harness 门禁或宣称 `delivery_ready`。
- 严格通过沿用 finalize 四文档；未完成只归档结论与原报告摘要，不生成通过版知识 MR。
- 发布分支前再次核验源码、材料、构建与结论；未知操作必须先恢复结算。
- 开发确认本地复核后幂等创建集成单，不代建或合并代码 MR，也不重复触发交接审查。
- 代码合入通过鉴权事件与 Git 历史核验；允许已交付提交的后继修复，但不扩大原验收覆盖。
- 严格通过任务在代码合入后回流知识，知识 MR 仍需人工审核及严格快照核验。
- 结论页面整理重复文本但保存原文，展示加工不改变失败语义或审核状态。

## 产物治理

归档只处理已结算、无引用、超过保留期的 previous HSP，任务须空闲且无恢复锁。
预览摘要绑定执行；扫描失败、链接、越界或内容变化均拒绝归档。先落索引和恢复来源，再移除原备份。
支持内容去重、压缩和原路径恢复；不同内容不覆盖，归档不自动永久删除。

## 验证

| 范围 | 关键检查 |
| --- | --- |
| 身份与审批 | 越权、旧材料、摘要变化、伪造决定与取消迟到输出 |
| 续行与恢复 | 停止收据、未决工具、会话隔离、幂等和预算 |
| 审查与构建 | 缺页、变化文件、过期报告、旧包、参数与路径 |
| 设备与结论 | fixture 缺项、失败保留、连续帧、跨包拒绝、未完成交接 |
| 发布与回流 | 真实 Git、后继提交、Webhook 身份、重复确认与通知 |
| 归档 | 引用保护、互斥、摘要变化、恢复和禁止覆盖 |

执行 `npm run test:cloud-agent`、`npm run typecheck`；运行时冒烟与真实设备验收分别记录，不互相替代。
