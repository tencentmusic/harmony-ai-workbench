# 设备结论展示整理

## 范围

设备验收与提测交接复用同一展示组件。优先显示真实结论与结构化分项状态；历史 reason
按分号、换行拆为有序记录，仅合并相同条目，保留不同尝试、否定语句和证据路径。
内联代码与代码块中的分隔符不拆分。原始 reason、blockers、完整源码及媒体/报告哈希可展开追溯。
不修改 Harness 合同、数据库、验收状态、审批或发布门禁，不重新运行历史任务。
默认显示前四条记录，其余记录可展开并连续编号，避免长结论占满交接页面。

## 实施与验证

1. 增加历史文本整理回归：重复原因、不同失败尝试、代码、路径、空记录。
2. 两个环节接入同一组件，状态明确标为通过、待解决或未完成。
3. 类型/架构与相关回归检查；用真实历史文本进行桌面、窄屏展示核验。

回退只需还原前端展示，无数据迁移。

## 结果

- 19 项展示整理、阶段流转和设备进度回归通过；类型、架构与更新日志检查通过。
- 用页面可见的历史结论渲染实际组件，确认重复记录合并、原文完整保留及详情默认折叠。
- 生成未完成、通过、空说明三个本地 HTML 预览。内置浏览器拒绝 file 协议，未完成浏览器截图及窄屏实际渲染验证。
