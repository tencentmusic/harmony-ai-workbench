# 模拟器录屏与设备动作恢复

## Spec

测试服模拟器的系统录屏服务可能创建媒体 URI 后在 AVRecorder Prepare 阶段失败，留下 0 字节 MP4。该状态不是视频证据；导出命令失败时应先核对原媒体大小。原媒体非空且 URI 导出失败时，可对媒体库返回的受限路径做只读拉取，并校验完整 MP4、时长和视频轨。录屏失败不重放同一后端，也不阻止无视频依赖的场景。

设备滑动命令已返回成功、动作后截图已落盘，但后置层级因时间不足超时的收据，应允许原操作 ID 做一次仅核对旧证据的结算。结算结果为动作已派发但后置观察不足，不能作为业务 PASS；随后新建只读观察。原动作命令结果或截图哈希不可信时保持未决。普通业务弹窗与已批准的业务交互不因按钮文案被一概拒绝。

## Plan

1. 在 Harness 补录屏导出诊断、非空原路径兜底及同 ID 恢复；旧收据核验出零字节时写独立失败结算，保留原始收据。
2. 在 Harness 补成功滑动加后置层级超时的受限结算，不重放动作；未知结果仍锁定设备。
3. 在工作台将内部视频失败反馈给续跑器，并对可结算的滑动未决给一次原 ID 恢复机会；其他未决保持停止。
4. 回归录屏、设备和云 Agent 续跑测试，检查类型与架构；MR 合入后在测试服核对原任务和设备锁，再继续模拟器验收。
